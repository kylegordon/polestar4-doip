# Content patterns that must never be published, one extended regex per line, matched case-insensitively.

# (tool/p4doip/site/gate.py). Lines starting with # and blank lines are ignored. Patterns use character
# classes so this file never matches itself.

\+[1-9][0-9]{1,2}[ -]?[0-9]{2,4}[ -]?[0-9]{3,4}[ -]?[0-9]{3,4}
# Home paths:
/hom[e]/[a-z]
